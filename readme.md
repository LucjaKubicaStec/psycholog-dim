# Psycholog DiM

Statyczna strona internetowa gabinetu psychologicznego oferującego wsparcie dla dzieci, młodzieży i rodziców.

## Zawartość projektu

- `index.html` – główna strona z ofertą, kwalifikacjami i kontaktem.
- `styles.css` – style i układ responsywny.
- `logo.png` i `Ja.jpg` – grafiki używane na stronie.
- `CNAME` – konfiguracja domeny dla hostingu statycznego.

## Co zostało usprawnione

- uporządkowana, profesjonalna struktura treści i nawigacja,
- poprawione znaczniki semantyczne (nagłówek, sekcje, nawigacja, stopka),
- przygotowanie pod SEO: meta description, canonical, Open Graph, Twitter cards,
- dodane dane strukturalne Schema.org (`JSON-LD`) dla lokalnej usługi psychologicznej,
- wzmocniona czytelność i responsywność interfejsu.

## Uruchomienie

Projekt nie wymaga instalacji zależności. Aby uruchomić stronę lokalnie, otwórz plik `index.html` w przeglądarce.
