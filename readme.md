# Psycholog DiM

Prosta statyczna strona internetowa dla gabinetu psychologicznego oferującego wsparcie dla dzieci i młodzieży.

## Zawartość projektu

- `index.html` - główna strona z opisem, kwalifikacjami i sekcją kontaktową
- `styles.css` - style strony
- `logo.png` - logo używane w nagłówku

## Uruchomienie

Projekt nie wymaga instalacji zależności. Aby uruchomić stronę lokalnie, otwórz plik `index.html` w przeglądarce.

## Uwagi

Strona jest napisana w HTML i CSS i ma układ responsywny dla urządzeń mobilnych.
